# 佩知 · Pagewise v0.4.15

首个 GitHub 发布版本：中文摘要、选词与整段翻译、原文定位，以及基于当前文章的多轮问答。

## 安装

1. 下载下方 `pagewise-chrome-0.4.15.zip` 并解压。
2. 打开 Chrome 的 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。
4. 刷新网页，在佩知设置中填写自己的 API Key。

需要 Chrome 116+。默认模型为 `glm-5.3-flash`，支持自定义兼容 Chat Completions 的 HTTPS 接口。模型可用性以服务商及账号权限为准。

## 本版功能

- 悬浮小企鹅入口，侧栏平滑展开；摘要与提问分别放在两个 Tab。
- 中文摘要与问答附带原文引用，点击即可定位。
- 短词翻译自动补齐单词，悬停显示译文并高亮原文。
- 长选区补全完整段落，逐段显示中文译文并对齐原文留白。
- 同一页面关闭再打开保留内容、草稿、Tab 和滚动位置。
- 统一企鹅加载动画，支持系统减少动态效果设置。
- API Key 保存在本机，不内置密钥；内容仅在主动操作时发送给配置的模型服务。

附带 SHA-256 校验文件。GitHub 自动生成的 Source code 是源码，不是可直接加载的扩展安装包。更新时替换原加载目录中的文件，再重新加载扩展并刷新网页。

验证使用单元测试和模拟模型服务的 Chromium 浏览器回归，不需要真实 API Key。
