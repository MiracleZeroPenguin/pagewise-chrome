# 佩知 · Pagewise v0.4.17

本次更新优化侧栏初始界面和摘要生成状态。

- 初始状态使用新的小企鹅插画，替换原来的四角星。
- 生成摘要时，动态小企鹅居中显示在主体区域，下方显示“正在生成摘要...”。
- 去掉摘要生成时顶部的绿色加载提示条，并隐藏初始引导内容。
- 生成结束后显示摘要；生成失败时保留已有摘要，仍可重试。

## 安装与更新

下载 `pagewise-chrome-0.4.17.zip` 并解压。在 Chrome 的 `chrome://extensions` 中开启「开发者模式」，选择「加载已解压的扩展程序」，加载包含 `manifest.json` 的文件夹。

已有用户：用新文件替换原加载目录中的内容，在扩展管理页点击「重新加载」，再刷新网页。保留原加载路径即可沿用已有设置。

需要 Chrome 116+ 和自己的模型 API Key。附带 SHA-256 校验文件。GitHub 自动生成的 Source code 为源码，并非可直接加载的安装包。

已通过 68 项单元测试及使用模拟模型服务的 Chromium 浏览器回归。
